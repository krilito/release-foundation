# 壳聚糖简表说明

先用 `jianbiao.xlsx`。

数据库版和校验文件已经收进 `旧版/`，先不用看它们。

这版只保留最关键的信息，目标不是“记录一切”，而是趁样本还没丢，把最值钱的信息救下来。

文件：

- `sample.csv`
- `release.csv`

## 表1：样本与表征表

文件：

- `sample.csv`

一组样品一行。

最重要的是这几列：

- `锁定配方编号F1_F6`
- `实验原始组号`
- `DEX实际装载量`
- `DEX包封率_pct`
- `粒径_nm`
- `PDI`
- `Zeta电位_mV`
- `24h溶胀比`

这张表回答的是：

- 这组样品到底是谁；
- 样品里真正装了多少药；
- 颗粒/界面状态是什么样；
- 凝胶吸水状态怎么样。

## 表2：释药原始记录表

文件：

- `release.csv`

每个时间点、每个重复一行。

最重要的是这几列：

- `锁定配方编号F1_F6`
- `实验原始组号`
- `药物`
- `重复编号`
- `时间_h`
- `原始吸光度`
- `空白吸光度`
- `稀释倍数`
- `标准曲线编号`
- `累计释放率_pct`

这张表回答的是：

- 每个时间点原始读数是什么；
- 后面的 `Qt` 是怎么算出来的；
- 如果再出现 `Qt > 100%`，能不能回头查到问题。

## 锁定编号对应关系（已按实验方案表4锁定）

- `F1`：HA 低分子量，无 PVP
- `F2`：HA 低分子量，PVP 220 kDa
- `F3`：HA 低分子量，PVP 1300 kDa
- `F4`：HA 高分子量，无 PVP
- `F5`：HA 高分子量，PVP 220 kDa
- `F6`：HA 高分子量，PVP 1300 kDa

- `组1 = F2 = A1B1 = HA 20-40 + PVP 220 kDa`
- `组2 = F3 = A1B2 = HA 20-40 + PVP 1300 kDa`
- `组3 = F5 = A2B1 = HA 40-80 + PVP 220 kDa`
- `组4 = F6 = A2B2 = HA 40-80 + PVP 1300 kDa`
- `组5 = F1 = A1B0 = HA 20-40 + 无 PVP`
- `组6 = F4 = A2B0 = HA 40-80 + 无 PVP`

以上映射按实验方案页中的正交设计表（表3/表4）锁定，不再作为待确认项。

## 最低限度填写原则

如果时间非常紧，只保这三类信息：

1. 真实装载量 / 包封率
2. 粒径、PDI、Zeta
3. 每个时间点的原始吸光度，不要只留平均释放率

这已经足够区分：

- 是样品状态真的不同，
- 还是 assay / 分母 / 标准曲线出了问题。
