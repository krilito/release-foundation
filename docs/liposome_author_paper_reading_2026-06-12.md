Date: 2026-06-12

Paper:

Yanes et al., "A machine learning workflow to accelerate the design of in vitro
release tests from liposomes", Digital Discovery, 2025, 4, 2983-2993.

Links:

- RSC version of record: https://doi.org/10.1039/D5DD00112A
- Public code: https://github.com/danielyanes22/accelerated_IVR
- Downloaded local PDF cache:
  `../data/external/accelerated_IVR/paper/yanes_2025_liposome_ivr_ml.pdf`

## Purpose

The paper addresses a practical liposome IVR problem: release profiles depend
on formulation properties, drug type, lipid properties, and IVR assay
conditions, but the field lacks a standardized quantitative way to connect
those variables to release behavior.

Their stated goal is not continuous future-curve forecasting. The actual
machine-learning target is:

```text
formulation / IVR descriptors -> kinetic class
```

where kinetic class means slow, medium, or fast release.

## Technical Workflow

1. Literature curation:
   - 34 academic publications.
   - 141 formulations.
   - 22 active compounds.
   - 31 excipients/lipids.
   - 271 IVR tests.

2. Curve extraction:
   - Release plots digitized using WebPlotDigitizer.
   - Data stored in a SQLite relational schema.

3. Kinetic fitting:
   - 209 release profiles passed quality appraisal.
   - Six kinetic models screened: zero-order, first-order, Higuchi,
     Korsmeyer-Peppas, Weibull, Reciprocal.
   - Parameters fitted by least squares.
   - 100 Latin-hypercube initializations per model/profile.
   - Best fit selected by MAE.
   - f2 > 50 used as the acceptability threshold.

4. Weibull selection:
   - Reciprocal had strong RRMSE/AIC, but Weibull retained more acceptable
     profiles and was judged more general.
   - Weibull failed on some biphasic curves.
   - 197 profiles remained after f2/biphasic filtering.
   - Only hour-unit profiles were kept for standardized 0-24 h clustering,
     leaving 169 profiles.

5. Kinetic-class construction:
   - Weibull alpha/beta used to simulate release profiles over 0-24 h.
   - Simulated curves represented by 500 time columns.
   - PCA reduced profiles to two principal components retaining about 95%
     variance.
   - KMeans clustered PC scores.
   - k = 3 selected, interpreted as slow / medium / fast.

6. ML classification:
   - Kinetic class is merged back to static formulation/IVR descriptors.
   - Clean ML dataset shrinks to 77-78 rows depending on feature set.
   - Seven classifiers tested: DTC, SVC, GaussianNB, KNN, LogisticRegression,
     RandomForest, XGBoost.
   - Backward feature elimination selects 7 features.
   - Testing uses stratified 5-fold CV.
   - Metrics: balanced accuracy, micro-F1, MCC.

7. Interpretation:
   - SHAP on XGBoost is used to rank drivers of kinetic class.
   - pH, temperature, lipid/excipient descriptors are highlighted.

## What They Actually Predict

They predict:

```text
media_pH
media_temp_oC
drug_loading
Z_average_nm
API_type
weighted_Mw
weighted_Tm
    -> slow / medium / fast kinetic class
```

They do not predict:

```text
continuous Q(t)
future release after early observations
curve uncertainty
experimental stopping rules
new-system transfer
```

## Reported Performance

Paper-level headline:

- XGBoost balanced accuracy: 0.70 +/- 0.03.
- Random baseline: about 0.33.
- Permutation test p-value: 0.001.
- Test fold size: about 15-16 samples.
- XGBoost is chosen mainly because it had the lowest variance, not because it
  significantly beat every classifier.

Our local reproduction from the open code:

- XGBClassifier balanced accuracy: 0.697.
- F1: 0.702.
- MCC: 0.547.

This matches the paper-level story.

## Strengths

1. The data workflow is the real contribution.
   The paper turns scattered literature plots into a structured release
   database and reproducible code.

2. The kinetic-class construction is useful.
   Fitting Weibull theta, simulating curves, then clustering shape gives an
   auditable intermediate target.

3. The authors are honest about several weaknesses.
   They explicitly mention overfitting, limited cleaned sample size, categorical
   label-encoding drawbacks, non-causality of SHAP, and unproven
   generalisability.

4. It is open enough to benchmark against.
   Code and processed data are available, and we reproduced the core
   classifier result.

## Weaknesses

1. The headline can sound like curve prediction, but the endpoint is class
   prediction.
   This is the biggest mismatch with our project. A 0.70 kinetic-class balanced
   accuracy is not a continuous future-release predictor.

2. The model target is generated by the authors' own pipeline.
   The labels are not experimental mechanism labels. They are Weibull/PCA/KMeans
   shape labels.

3. Data shrinkage is severe.
   The workflow starts from 271 IVR tests, then 209 fit-quality profiles, 197
   Weibull-acceptable profiles, 169 hour-unit clustering profiles, and finally
   77-78 clean ML rows.

4. Evaluation is relatively easy.
   The headline test uses stratified random folds, not group-by-drug,
   group-by-assay, group-by-source, or prospective splits.

5. Some preprocessing choices are weak under strict ML standards.
   The public `testing_scores.py` scales all X before CV, which is mild
   preprocessing leakage. Categorical features are label-encoded, which can
   distort tree/SHAP interpretation.

6. Training overfit is visible.
   Tree models reach perfect training performance; paper acknowledges this and
   attributes it to small data after cleaning.

7. Weibull is convenient but incomplete.
   Biphasic profiles are removed, and the paper itself notes Weibull does not
   describe them sufficiently.

8. No uncertainty or observation-budget framing.
   The paper does not ask which early timepoints matter, whether uncertainty
   contracts, or when an experiment can stop.

## Meaning For Our Project

This paper is not a competitor to our PLGA information-budget story. It is a
useful second-system scaffold.

Their strongest asset for us is the middle layer:

```text
curve -> Weibull alpha/beta -> kinetic class
```

Our scripts 112 and 113 already tested the reverse use:

```text
static / static+early Q -> class or theta middle layer -> Q(t)
```

The result is consistent with our route:

- static descriptors contain some release-shape signal;
- early Q improves routing;
- 3-class kinetic labels are too coarse;
- strict group splits still favor early-observation / theta routes.

## Practical Decision

Use Yanes et al. as the author baseline and data scaffold, but do not let their
classification endpoint define our endpoint.

The next fair experiment is E3:

```text
k = 0, 1, 2, 3, 5 measured early observations
compare:
  author class-prototype baseline
  early-only Weibull fit
  static+early theta model
  prototype mixture
  refined prototype initialization
```

The claim should remain:

```text
Liposome static descriptors give a coarse kinetic prior;
early release observations expose curve-specific state;
prediction should be evaluated as observation-budgeted future-release
forecasting, not only static kinetic-class classification.
```
