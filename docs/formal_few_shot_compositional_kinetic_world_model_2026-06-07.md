# A Formal Note on Few-Shot Compositional Kinetic World Models for Drug Release

This note is meant to fix the mathematical object before the modeling work runs ahead of the science. The problem is not to find a more impressive name for a curve predictor. The problem is to decide whether drug-release forecasting can be placed inside a coherent state-space language: a language in which material identity, processing history, and release environment act on latent kinetic states, sparse early observations update beliefs about those states, and future release is predicted through constrained kinetic decoders.

The central claim is intentionally precise. A direct map

$$
x\mapsto \widehat Q(t)
$$

is not a world model. It may be a useful regression model, but it contains no explicit state of the release system and no mathematical account of how that state changes when a material, process, or environment is changed. A more defensible object is

$$
\text{typed operators}
\rightarrow
\text{kinetic state}
\rightarrow
\text{Bayesian observer update}
\rightarrow
\text{future predictive law}.
$$

The purpose of this note is to define that object, state what can be proved locally, and mark the points where empirical validation rather than algebra must carry the claim.

## 0. World-model status as an evolutionary claim

The phrase "world model" is not used loosely. It refers to a mathematically staged program, not to a finished universal simulator. The stages are:

$$
\text{Curve predictor}
\;\Rightarrow\;
\text{Kinetic observer}
\;\Rightarrow\;
\text{Typed operator model}
\;\Rightarrow\;
\text{Few-shot adaptive world model}
\;\Rightarrow\;
\text{Evolving chart-transition world model}.
$$

Each stage is strictly more structured than the previous one.

**Stage 1, curve predictor.** A map $x\mapsto\widehat Q(t)$ has no latent state and no belief update. It is regression, not a world model.

**Stage 2, kinetic observer.** A Bayesian system $x\mapsto p_0(s\mid x)$, $C_k\mapsto p(s\mid x,C_k)$, $s\mapsto Q(t)$ has latent kinetic state and a posterior update rule. It answers the question "what state is compatible with my observations?" This is a proto-world-model: it models the release system's internal state, not merely its output.

**Stage 3, typed operator model.** Material, process, and environment act as typed transformations $T_m^f$, $T_p^f$, $T_e^f$ on kinetic state. The system's state is not merely inferred but generated by compositional operations. This is world-model-like because it answers the counterfactual-adjacent question "how would the state change if a generating factor changed?"

**Stage 4, few-shot adaptive world model.** A source-specific correction $\Delta_r$ is inferred from sparse early observations. The system adapts to new experimental contexts without retraining. This strengthens the world-model claim because the state is jointly determined by operators and observation.

**Stage 5, evolving chart-transition world model.** Future versions may allow operators to move between kinetic grammar charts through transition kernels

$$
K_a(f',\eta_{f'}\mid f,\eta_f),
$$

enabling material, process, or environment changes to shift the system from one kinetic grammar to another (e.g., from single-phase Weibull to biphasic biexponential release). This is the most complete form of the program, but it is not required for the current stage.

Ambition is not reduced; it is staged. The current note targets Stages 2–4. Stage 5 is a defined future route, not a present claim.

## 1. Kinetic state space

Let \(\mathcal F\) be a finite set of kinetic grammar families. In the present project one may take

$$
\mathcal F
=
\{\mathrm{Weibull},\mathrm{biexponential},\mathrm{Hill}\}.
$$

These families are not physical mechanisms. They are constrained coordinate charts for monotone release curves. Since different families may have different parameter dimensions, the state space should not be treated as a single Euclidean space. For each \(f\in\mathcal F\), let

$$
\Theta_f\subseteq \mathbb R^{d_f}
$$

be the admissible parameter space for that family, and let \(\sigma\in\mathbb R_{>0}\) denote an observation-noise scale. The kinetic state space is the disjoint union

$$
\mathcal S
=
\bigsqcup_{f\in\mathcal F}
\{f\}\times \Theta_f\times \mathbb R_{>0}.
$$

A state is therefore

$$
s=(f,\theta_f,\sigma).
$$

A convenient measurable structure is the \(\sigma\)-algebra generated by the
family-wise rectangles,

$$
\mathcal B(\mathcal S)
=
\sigma\!\left(
\left\{
\{f\}\times A_f\times B_f
:
f\in\mathcal F,\;
A_f\in\mathcal B(\Theta_f),\;
B_f\in\mathcal B(\mathbb R_{>0})
\right\}
\right).
$$

Because \(\mathcal F\) is finite, this coincides with the coproduct
(direct-sum) \(\sigma\)-algebra \(\bigoplus_{f\in\mathcal F}\bigl(\mathcal B(\Theta_f)\otimes\mathcal B(\mathbb R_{>0})\bigr)\): a set is measurable iff each of its fibers is. The single-rectangle-per-fiber sets above generate this \(\sigma\)-algebra but are not closed under complementation, so they form a generating \(\pi\)-system rather than the \(\sigma\)-algebra itself.

With this structure, a prior conditional on descriptors \(x\) can be written family-wise as

$$
P_0(ds\mid x)
=
\sum_{f\in\mathcal F}
\pi_0(f\mid x)
P_0(d\theta_f,d\sigma\mid f,x).
$$

This notation matters. It prevents the model from pretending that Weibull, biexponential, and Hill parameters live in the same coordinate system.

## 2. Admissible latent release curves

Let the latent clean release curve space be

$$
\mathcal Q
=
\left\{
Q:[0,\infty)\to[0,1]:
Q \text{ is absolutely continuous and nondecreasing}
\right\}.
$$

For each family \(f\), define a decoder

$$
G_f:\Theta_f\to\mathcal Q,
\qquad
G_f(\theta_f)(t)=g_f(t;\theta_f).
$$

Thus an admissible decoder must satisfy

$$
G_f(\Theta_f)\subseteq\mathcal Q.
$$

Equivalently, for all \(t\geq 0\) and all admissible \(\theta_f\),

$$
0\leq g_f(t;\theta_f)\leq 1,
\qquad
\frac{\partial}{\partial t}g_f(t;\theta_f)\geq 0
$$

where the derivative exists almost everywhere. Observation noise may push measured values outside the ideal range, but the latent clean curve should remain bounded and monotone.

For example, one may use the following constrained families.

The Weibull family:

$$
g_{\mathrm W}(t;Q_\infty,k,\beta)
=
Q_\infty
\left[
1-\exp\{-(kt)^\beta\}
\right],
$$

with

$$
0<Q_\infty\leq 1,\qquad k>0,\qquad \beta>0.
$$

The biexponential family:

$$
g_{\mathrm B}(t;Q_\infty,a,k_1,k_2)
=
Q_\infty
\left[
1-ae^{-k_1t}-(1-a)e^{-k_2t}
\right],
$$

with

$$
0<Q_\infty\leq 1,\qquad 0\leq a\leq 1,\qquad 0<k_1\leq k_2.
$$

The ordering constraint $k_1\leq k_2$ is required for identifiability. Without it, the parameterizations $(a,k_1,k_2)$ and $(1-a,k_2,k_1)$ produce the same curve. One may equivalently rename the rates $k_{\mathrm{slow}}$ and $k_{\mathrm{fast}}$ with $k_{\mathrm{slow}}\leq k_{\mathrm{fast}}$. The boundary case $a=0$ or $a=1$ collapses the biexponential to a single exponential and should be treated as a degenerate subfamily.

Then

$$
\frac{d}{dt}g_{\mathrm B}(t)
=
Q_\infty
\left[
ak_1e^{-k_1t}+(1-a)k_2e^{-k_2t}
\right]\geq 0.
$$

The Hill family:

$$
g_{\mathrm H}(t;Q_\infty,K,n)
=
Q_\infty
\frac{t^n}{K^n+t^n},
$$

with

$$
0<Q_\infty\leq 1,\qquad K>0,\qquad n>0.
$$

These forms are not asserted to be physical laws. They are admissible kinetic grammars. Their role is to provide a low-dimensional, constrained representation of release trajectories.

## 3. Unconstrained coordinates

For local modeling and operator calculus, it is convenient to work in unconstrained coordinates. For each family \(f\), let

$$
h_f:\Theta_f\to H_f\subseteq\mathbb R^{d_f}
$$

be a smooth reparameterization, and write

$$
\eta_f=h_f(\theta_f),
\qquad
\theta_f=h_f^{-1}(\eta_f).
$$

For example,

$$
h_{\mathrm W}(Q_\infty,k,\beta)
=
(\operatorname{logit}Q_\infty,\log k,\log\beta)
$$

on the open parameter domain \(Q_\infty\in(0,1)\), \(k>0\), \(\beta>0\). The formal reparameterization \(h_f\) is defined on the interior of \(\Theta_f\); boundary cases such as \(Q_\infty=1\) or \(a\in\{0,1\}\) in the biexponential family are limiting cases or degenerate subfamilies where the unconstrained coordinate map is not a diffeomorphism. Throughout the operator calculus we work on the open domain and treat boundary cases separately.

Operators will act on \(\eta_f\), not directly on \(\theta_f\). This keeps the state coordinates locally linear while the inverse map \(h_f^{-1}\) enforces physical constraints.

One caveat: a coordinatewise transform enforces only *box* constraints. The joint ordering constraint \(k_1\leq k_2\) of the biexponential family is **not** enforced by \((\log k_1,\log k_2)\), whose image is all of \(\mathbb R^2\); an operator acting on such coordinates can leave the identifiable region. To keep the ordered region invariant one must reparameterize the constraint itself, e.g. \((\log k_1,\ \log(k_2-k_1))\) (a slow rate plus a nonnegative log-gap), or project operator outputs back onto the feasible set.

## 4. Typed kinetic operators

Let \(\mathcal M\), \(\mathcal P\), and \(\mathcal E\) denote descriptor spaces for material, processing, and release environment respectively. For each family \(f\), define typed maps

$$
T_m^f:\mathcal M\times H_f\to H_f,
$$

$$
T_p^f:\mathcal P\times H_f\to H_f,
$$

$$
T_e^f:\mathcal E\times H_f\to H_f.
$$

Given material \(m_i\), process \(p_i\), and environment \(e_i\), define the composed operator

$$
T_{m_i,p_i,e_i}^f
=
T_e^f(e_i,\cdot)
\circ
T_p^f(p_i,\cdot)
\circ
T_m^f(m_i,\cdot).
$$

The family-specific coordinate for sample \(i\) is

$$
\eta_{fi}
=
T_{m_i,p_i,e_i}^f(\eta_0^f)
+\varepsilon_i.
$$

At this stage we assume these operators preserve the grammar family:

$$
T_a(f,\eta_f)=(f,T_a^f\eta_f).
$$

This is a controlled first-stage simplification, not a final limitation. Since $f$ indexes a kinetic chart rather than a physical mechanism, later versions of the model may replace family-preserving maps with transition kernels over the disjoint-union state space,

$$
K_a(f',\eta_{f'}\mid f,\eta_f),
$$

allowing material, process, or environment changes to move the system between kinetic grammar charts. The family-preserving assumption is the starting point of the evolutionary route described in Section 0, not its endpoint.

The operators must also be restricted enough that the operator class does not collapse into unconstrained regression. A minimal structural requirement is low-dimensional, source-shared parameterization. For example,

$$
T_a^f(z,\eta)=\eta+\Phi_a^f(z;\omega_a),
$$

where $\Phi_a^f$ is a low-dimensional function with shared parameters $\omega_a$ across sources, or

$$
T_a^f(z,\eta)=A_a^f(z)\eta+b_a^f(z),
$$

with $A_a^f$ and $b_a^f$ parameterized by a small number of source-shared weights. Without such restrictions, $T_a^f(z,\cdot)$ becomes an arbitrary map from $H_f$ to $H_f$ for each $z$, and the operator model reduces to a per-sample interpolator with no generalization structure.

These two forms are not interchangeable for the argument that follows. The purely additive form $T_a^f(z,\eta)=\eta+\Phi_a^f(z)$ **commutes**: $T_p^fT_m^f\eta=\eta+\Phi_m+\Phi_p=T_m^fT_p^f\eta$, so it carries none of the order-dependent (noncommutative) structure emphasized below, and on $\eta$ it *is* additive covariate regression — exactly the object an operator model is meant to be distinguished from. The noncommutative content therefore lives entirely in the affine form $T_a^f(z,\eta)=A_a^f(z)\eta+b_a^f(z)$ with non-commuting linear parts $A^f$. If noncommutativity is to be load-bearing (Section 5), the model must commit to the affine form, and the claim $[A_p,A_m]\neq 0$ must itself be made empirically testable rather than assumed.

The order of composition is meaningful. Processing acts on the material object before the release environment acts on the processed object. In general one should not assume

$$
T_e^f(e,\cdot)\circ T_p^f(p,\cdot)
=
T_p^f(p,\cdot)\circ T_e^f(e,\cdot).
$$

This noncommutativity is part of why an operator model is different from an ordinary descriptor regression.

## 5. Additive approximation and its limitation

A practical first approximation is the local additive model

$$
\eta_f
=
\mu_f
+A_fz_{\mathrm{material}}
+B_fz_{\mathrm{process}}
+C_fz_{\mathrm{env}}
+u_{\mathrm{source}}
+\varepsilon.
$$

This should be read as a first-order coordinate surrogate for the operator system, not as the world model itself. To see what is lost, suppose locally

$$
T_m(\eta)=(I+A_m)\eta,
\qquad
T_p(\eta)=(I+B_p)\eta.
$$

Then

$$
T_pT_m\eta
=
(I+B_p)(I+A_m)\eta
=
\eta+A_m\eta+B_p\eta+B_pA_m\eta,
$$

whereas

$$
T_mT_p\eta
=
(I+A_m)(I+B_p)\eta
=
\eta+B_p\eta+A_m\eta+A_mB_p\eta.
$$

The first-order terms agree. The order-dependent term is the commutator

$$
[B_p,A_m]\eta
=
B_pA_m\eta-A_mB_p\eta,
$$

which appears at second order. Thus the additive model may be useful for fitting and diagnostics, but it discards the interaction terms that would reveal noncommutative structure.

## 6. Few-shot adaptation as source correction

The few-shot problem should not be formulated as retraining a large predictor on a small number of samples. The sharper question is whether a small number of early observations can identify a low-dimensional correction to the operator system for a new source, paper, or experimental setting.

Let source \(r\) have a correction

$$
\Delta_r\in\mathbb R^{d_\Delta},
\qquad
d_\Delta\ll d_f.
$$

For sample \(i\) from source \(r\), write

$$
\eta_{ri}
=
T_{m_{ri},p_{ri},e_{ri}}^{f_i}(\eta_0^{f_i})
+D_{ri}\Delta_r
+\varepsilon_{ri}.
$$

The observed release at time \(t_{rij}\) is

$$
Y_{rij}
=
G_{f_i}
\left(
h_{f_i}^{-1}(\eta_{ri})
\right)(t_{rij})
+\xi_{rij}.
$$

The prefix observation set is

$$
C_{rk}
=
\{(t_{rij},Y_{rij}):t_{rij}\leq\tau_{rk}\}.
$$

Few-shot adaptation is posterior inference over \(\Delta_r\):

$$
p(\Delta_r\mid C_{rk},x_r)
\propto
p(C_{rk}\mid\Delta_r,x_r)p_0(\Delta_r).
$$

This formulation is meaningful only if early observations carry information about directions in \(\Delta_r\) that influence future release.

## 7. Proposition 1: local precision gain

Fix a family \(f\). Define the nonlinear observation mean

$$
\mu_i(\Delta_r)
=
G_f
\left(
h_f^{-1}(\eta_i^0+D_i\Delta_r)
\right)(t_i).
$$

Linearize around \(\Delta_r=0\):

$$
\mu_i(\Delta_r)
\approx
\mu_i(0)+J_i\Delta_r,
$$

where

$$
J_i
=
\left.
\nabla_{\Delta_r}
G_f
\left(
h_f^{-1}(\eta_i^0+D_i\Delta_r)
\right)(t_i)
\right|_{\Delta_r=0}
\in\mathbb R^{1\times d_\Delta}.
$$

Equivalently,

$$
J_i
=
\left.
\nabla_\eta
\left[
G_f(h_f^{-1}(\eta))(t_i)
\right]
\right|_{\eta=\eta_i^0}
D_i.
$$

Assume the linearized observation model

$$
y_C
\approx
\mu_C+J_C\Delta_r+\xi_C,
\qquad
\xi_C\sim\mathcal N(0,\Sigma_{\mathrm{obs}}),
$$

and a Gaussian prior

$$
\Delta_r\sim\mathcal N(0,\Sigma_\Delta).
$$

Then the linear-Gaussian posterior precision is

$$
\Sigma_{\Delta\mid C}^{-1}
=
\Sigma_\Delta^{-1}
+J_C^\top\Sigma_{\mathrm{obs}}^{-1}J_C.
$$

The proof is the standard completion of squares in the Gaussian log posterior. This proposition is exact for the linear-Gaussian approximation and local, in the Laplace or Gauss-Newton sense, for the nonlinear kinetic decoder.

The consequence is not that few-shot adaptation always works. The consequence is that early observations help only insofar as the row space of \(J_C\) covers directions of \(\Delta_r\) that affect future release.

To formalize this, define the future mean vector

$$
\mu_F(\Delta_r)=\left(\mu_i(\Delta_r)\right)_{t_i>\tau_k}
$$

and its Jacobian

$$
J_F=\nabla_{\Delta_r}\mu_F(\Delta_r)\big|_{\Delta_r=0}.
$$

A direction $v\in\mathbb R^{d_\Delta}$ is **dangerous** when

$$
v\in\ker(J_C)
\quad\text{but}\quad
v\notin\ker(J_F),
$$

meaning it is invisible to early observations but affects future release. Along such a $v$ the likelihood contributes no information, so the posterior *precision* is unchanged in that direction, $\Sigma_{\Delta\mid C}^{-1}v=\Sigma_\Delta^{-1}v$; equivalently, the conditional variance of $\langle v,\Delta_r\rangle$ given the remaining coordinates does not contract. (The *marginal* variance along $v$ can still shrink when the prior is correlated, through coupling to informed directions — so the correct invariant is the precision/conditional statement, not "the posterior does not contract"; see Appendix A.) Future prediction along $J_F v$ then remains uncertain however many early points are added **within the same early-time window**, i.e. whenever $v$ lies in the unobservable subspace of that window rather than merely in the kernel of the currently sampled design.

The few-shot claim is therefore not about the number of early observations but about whether the future-relevant subspace is observed. The correct requirement is the **containment**

$$
\operatorname{row}(J_F)\subseteq\operatorname{row}(J_C)
\qquad\Longleftrightarrow\qquad
\ker(J_C)\subseteq\ker(J_F),
$$

i.e. every direction that affects future release is already informed by the early observations. The intersection condition $\ker(J_C)\cap\operatorname{row}(J_F)=\{0\}$ is only *necessary*, not sufficient: two subspaces can meet trivially while a dangerous direction still exists (explicit counterexample in Appendix A).

This yields a practical diagnostic: under the fitted model, compute the principal angles between $\operatorname{row}(J_F)$ and $\operatorname{row}(J_C)$, or the residual energy $\bigl\|J_F\,(I-P_{\operatorname{row}(J_C)})\bigr\|$ of the future Jacobian after projecting onto the early-observable subspace. A large residual means some future-relevant direction is unobserved and the early-observation protocol is misaligned with the prediction target.

## 8. Bayesian observer update

For a general state \(s\in\mathcal S\), the Bayesian observer update is

$$
P(ds\mid x,C_k)
=
\frac{
p(C_k\mid s,x)P_0(ds\mid x)
}{
\int_{\mathcal S}p(C_k\mid s',x)P_0(ds'\mid x)
}.
$$

Family-wise, this can be written as

$$
p(f,\theta_f,\sigma\mid x,C_k)
=
p(f\mid x,C_k)
p(\theta_f,\sigma\mid f,x,C_k).
$$

This update is rigorous once the likelihood, prior, and reference measures are specified. It is not yet a claim about future prediction. Prediction requires a separate predictive law.

## 9. Latent and observed predictive laws

The latent clean curve is

$$
Q(t)=G_f(\theta_f)(t).
$$

The observed response is

$$
Y(t)=Q(t)+\xi(t),
$$

or, more generally, \(Y(t)\sim p_{\mathrm{obs}}(\cdot\mid Q(t),\sigma)\).

For \(t>\tau_k\), the latent predictive law is

$$
P(Q(t)\mid x,C_k)
=
\sum_{f\in\mathcal F}
\int
\delta_{G_f(\theta_f)(t)}
P(df,d\theta_f,d\sigma\mid x,C_k).
$$

The observed predictive law is

$$
p(y(t)\mid x,C_k)
=
\sum_{f\in\mathcal F}
\int_{\Theta_f\times\mathbb R_{>0}}
p_{\mathrm{obs}}
\left(
y(t)\mid G_f(\theta_f)(t),\sigma
\right)
p(f,\theta_f,\sigma\mid x,C_k)
d\theta_f\,d\sigma.
$$

For experimental forecasting, the natural risk is usually the observed future risk

$$
\mathcal R_{\mathrm{future}}(k)
=
\mathbb E
\left[
\sum_{t_j>\tau_k}
L
\left(
Y(t_j),
p(Y(t_j)\mid x,C_k)
\right)
\right].
$$

If a denoised full curve is treated as ground truth, one may also define a latent risk, but the target must be stated explicitly. No point in \(C_k\) should be included in a forecast score.

Throughout this note, observation noise is modeled as independent and additive Gaussian, $\xi(t)\sim\mathcal N(0,\sigma^2)$. This is the simplest tractable observation model. Real release data may require heteroscedastic noise (variance depending on $t$ or on $Q$), correlated noise (autocorrelation across time points), bounded noise (since $Y(t)\in[0,1]$ in principle), or normalization-aware noise models (when cumulative release is normalized to a final measured value). The mathematical framework does not depend on the Gaussian assumption, but the explicit formulas in Propositions 1 and 2 do. Extensions to non-Gaussian or correlated observation models replace $\Sigma_{\mathrm{obs}}^{-1}$ with the appropriate Fisher information or score function.

## 10. Proposition 2 (sanity bound): expected information gain

Because \(S\) is a hybrid discrete-continuous state, a KL formulation is safer than a primary differential-entropy formulation. Under a well-defined joint law for \(S,X,C_k\), mutual absolute continuity of the relevant conditional laws, and finite KL divergence,

$$
I(S;C_k\mid X)
=
\mathbb E_{X,C_k}
\left[
\mathrm{KL}
\left(
P(S\mid X,C_k)
\;\|\;
P(S\mid X)
\right)
\right]
\geq 0.
$$

This is immediate from nonnegativity of KL divergence. If a fixed reference measure and coordinate system are chosen and the entropies are finite, one may also write an entropy identity. But the KL form is the better primary statement.

This proposition does not imply that every realized prefix reduces uncertainty, that future prediction improves, that uncertainty contracts in future-relevant directions, or that the operator decomposition is identifiable. It says only that observations carry nonnegative expected information about the full state under the specified joint law.

More bluntly, the bound is a tautology: $I(S;C_k\mid X)\geq 0$ holds for *any* joint law and uses none of the kinetic, operator, or decoder structure, so it is a sanity statement rather than support for the model. The claim the program actually needs is the sharper, model-specific one that the prefix is informative in *future-relevant* directions — the containment $\operatorname{row}(J_F)\subseteq\operatorname{row}(J_C)$ of Section 7 — which does not follow from nonnegativity of mutual information and must be checked per design.

## 11. Proposition 3: a confounding obstruction

Consider the local additive approximation

$$
\eta
=
X_m\alpha
+X_p\beta
+X_e\gamma
+Zu
+\varepsilon,
$$

where \(X_m\), \(X_p\), and \(X_e\) are material, process, and environment design matrices, and \(Z\) is the source design matrix.

If there exist nonzero vectors \(v\) and \(w\) such that

$$
X_pv=Zw,
$$

then the process effect in direction \(v\) and the source effect in direction \(w\) are not separately identifiable from fitted values. Indeed, for any scalar \(c\),

$$
X_p(\beta+cv)+Z(u-cw)
=
X_p\beta+Zu+cX_pv-cZw
=
X_p\beta+Zu.
$$

Thus infinitely many parameter pairs produce the same linear predictor. In particular, if

$$
\operatorname{col}(X_p)\subseteq\operatorname{col}(Z),
$$

then process effects are perfectly confounded with source effects. More generally, if

$$
\operatorname{col}(X_p)\cap\operatorname{col}(Z)\neq\{0\},
$$

some process-source directions are not separately identifiable.

This is an obstruction, not a complete identifiability theorem. A full theorem would require specifying the fixed and random effect structure, variance components, constraints, and likelihood.

A local nonlinear version of the same obstruction holds for the full kinetic model. If the nonlinear predictive mean $\mu(\beta,u)$ has Jacobians

$$
J_\beta=\frac{\partial\mu}{\partial\beta},
\qquad
J_u=\frac{\partial\mu}{\partial u},
$$

and there exist nonzero vectors $v,w$ such that

$$
J_\beta v=J_u w,
$$

then process and source effects are locally confounded in the direction $(v,-w)$. This generalizes the linear rank-deficiency condition to the nonlinear decoder setting: the obstruction is not an artifact of the additive approximation but a structural feature of any model where source covariates overlap with process covariates in their effect on the predicted curve.

## 12. Validation hierarchy

Future-only validation is necessary but not sufficient. It prevents the model from being rewarded for predicting points used in the posterior update, but it does not prove that material, process, or environment operators have been learned.

The validation should therefore be stratified.

Level 1 is a time split within a release experiment. The model observes early time points and predicts later time points from the same curve. This tests the few-shot observer.

Level 2 is a sample split within the same source. The model holds out formulations or experiments while retaining paper or laboratory context. This tests within-source generalization.

Level 3 is a source-held-out or paper-held-out split. The model holds out entire papers, laboratories, or datasets. This tests whether the operator structure survives source shift.

Level 4 is descriptor and source ablation. The model should be compared against a prefix-only observer, a descriptor-only prior, a source-effect-only model, and operator models with material, process, or environment layers removed.

Level 5 is an identifiability audit. One should inspect ranks and condition numbers of design matrices, covariate overlap across sources, duplicate formulation leakage, missingness patterns, and paper-specific protocols.

Level 6 is a model-capacity fairness check. Operator models must be compared against baselines with matched or greater parameter capacity. An operator model with 50 parameters should not be declared superior to a descriptor regression with 200 parameters unless the comparison is capacity-controlled. Otherwise improvement, if any, cannot be attributed to compositional structure rather than to additional parameters.

Only if the operator layers improve prediction and calibration under grouped validation, and only if they survive identifiability and capacity audits, should the language of a compositional kinetic world model be used strongly.

## 13. The long-term route

The evolutionary program has four defined stages beyond the current work.

**Stage 1 (current).** Chart-preserving typed operators $T_m^f$, $T_p^f$, $T_e^f$ with family-specific parameterization. Source corrections $\Delta_r$ inferred from early observations.

**Stage 2.** Source-adaptive few-shot corrections with explicit alignment diagnostics between early-observation Jacobian $J_C$ and future-relevant Jacobian $J_F$. Protocol optimization: choose early time points to enforce the containment $\operatorname{row}(J_F)\subseteq\operatorname{row}(J_C)$ — equivalently, to minimize the residual energy $\|J_F(I-P_{\operatorname{row}(J_C)})\|$ of the future Jacobian after projection onto the early-observable subspace (Section 7; Appendix A).

**Stage 3.** Chart-transition kernels $K_a(f',\eta_{f'}\mid f,\eta_f)$ allowing material, process, or environment changes to move the system between kinetic grammar charts. This requires extending the state space to include cross-family transitions and re-deriving the Bayesian update on the full disjoint union.

**Stage 4.** Learned expansion or refinement of the kinetic grammar set $\mathcal F$ itself. If the current three families are insufficient, new constrained monotone families can be added (e.g., stretched exponential, power-law with saturation, multi-compartment models). The admissibility conditions—boundedness, monotonicity, and decoder injectivity—remain the mathematical gate for any new family.

Each stage is a testable extension, not a speculative leap. The program advances only if the current stage survives validation.

## 14. Defensible thesis

The thesis I would defend is the following:

$$
\textit{
Drug-release modeling can be formulated as a structured statistical state-space problem. Clean release curves are represented by constrained monotone kinetic grammar families. Material, process, and environment descriptors act as typed transformations on family-specific kinetic coordinates. Sparse early observations update a posterior over kinetic state or low-dimensional source corrections. Few-shot adaptation improves future prediction only when early observations carry information in directions that affect later release behavior. The operator interpretation is a testable statistical hypothesis, not a claim of causal physical mechanism without additional invariance, overlap, or intervention evidence.
}
$$

This is not a claim to have already built a universal drug-release foundation model. It is a precise mathematical program. The central mathematical problem is identifiability. The central statistical problem is posterior updating without leakage. The central scientific problem is collecting enough material, process, and environment variation to make the operators more than names for regression columns.

## 15. Practical modeling requirement

The project should now be organized around the following requirement:

$$
\mathcal M
=
(\mathcal S,\mathcal A,\mathcal O,T,U,G),
$$

where \(\mathcal S\) is the disjoint-union kinetic state space, \(\mathcal A\) is the typed material-process-environment descriptor space, \(\mathcal O\) is the observation space, \(T\) is the typed state transformation (family-preserving in the current stage, with chart-transition kernels as a defined future extension), \(U\) is the Bayesian observer update, and \(G\) is the constrained monotone release decoder.

The existing work has partial evidence for \(G\), because the kinetic grammar can fit full release curves well. The next work should not begin by enlarging the predictor. It should define and test \(T\) and \(U\): the operator transformations and the few-shot observer. If these two pieces do not survive source-aware validation, then the honest object is a kinetic observer rather than a world model. If they do survive, the project has a mathematically defensible route through the staged program: chart-preserving operators first, source-adaptive corrections second, chart-transition kernels third, grammar refinement fourth. Ambition is not reduced; it is staged.

## 16. Related formalisms and the precise novelty claim

The object defined above should be positioned explicitly against existing formalisms, because most of its components already have standard names. Stating the overlap is what makes the genuinely new part legible.

**Nonlinear mixed-effects / population PK–PD.** A structural curve $Y_{ij}=g_f(t_{ij};\theta_i)+\xi_{ij}$ with a parameter-level covariate model $\eta_i=g(x_i;\beta)+u_i$ and random effects $u_i$ is exactly the nonlinear-mixed-effects (NLME) / population-PK construction [cite: Davidian & Giltinan; Bonate; NONMEM, Monolix]. The typed operators $T_m,T_p,T_e$ are a structured covariate model on $\eta$; the kinetic families are candidate structural models.

**Bayesian forecasting / individualization.** Inferring a low-dimensional source correction $\Delta_r$ from a few early points and predicting the rest is Sheiner-style Bayesian forecasting / therapeutic drug monitoring [cite: Sheiner et al. 1979; MAP Bayesian estimation], i.e. conditional (empirical-Bayes) estimation of individual random effects. "Few-shot" is a reframing of this conditioning, not a new estimator.

**Optimal experimental design.** The $J_C/J_F$ alignment of Section 7 is a prediction-oriented design criterion; choosing early time points to inform future-relevant directions is $c$-/$D_s$-optimal design on the Fisher information $J_C^\top\Sigma_{\mathrm{obs}}^{-1}J_C$ [cite: Fedorov; Atkinson; PopED/PFIM]. The contribution is the *target subspace* $\operatorname{row}(J_F)$, not the design machinery.

**World models / latent dynamics.** Model-based "world models" [cite: Ha & Schmidhuber; Dreamer; JEPA] carry a *learned transition law over time* and typically an action/planning loop. The present object has neither: the latent $\eta$ is static per configuration, $t\mapsto Q(t)$ is a fixed parametric map, and the operators act across configurations, not across time. Until Stage 5 introduces genuine time/intervention dynamics, "world model" is used in a weak, aspirational sense and should be flagged as such.

**What is genuinely new (and should be the headline).** Three claims survive the overlap and are worth defending precisely:

1. *Family-as-state, with cross-chart inference.* Carrying the discrete kinetic family $f$ inside the state and inferring/transporting across charts (Stages 3–5) is not standard population PK, which fixes the structural model.
2. *Compositional, explicitly noncommutative typed operators.* If the affine non-commuting form is adopted and $[A_p,A_m]\neq0$ is shown empirically necessary (Section 5), the operator structure is more than additive covariates.
3. *Future-relevant design and the dangerous-direction diagnostic.* The $\operatorname{row}(J_F)\subseteq\operatorname{row}(J_C)$ requirement and its residual-energy diagnostic (Section 7; Appendix A) target *forecast* identifiability under grouped, capacity-controlled validation (Section 12).

Everything else in the note is a careful restatement of NLME + Bayesian forecasting + optimal design and should be presented as such rather than as new machinery. [Author: replace bracketed pointers with proper citations.]

## Appendix A. Corrected statements and counterexamples

This appendix records the two corrections to Section 7 and the precise form of the dangerous-direction condition.

### A.1 Observability condition (correct form)

Let $J_C\in\mathbb R^{n_C\times d_\Delta}$ and $J_F\in\mathbb R^{n_F\times d_\Delta}$ be the early- and future-observation Jacobians of the linearized observation mean with respect to $\Delta_r$. Call $v\in\mathbb R^{d_\Delta}$ **dangerous** if $v\in\ker(J_C)$ and $v\notin\ker(J_F)$.

**Proposition A.1.** No dangerous direction exists iff

$$
\ker(J_C)\subseteq\ker(J_F)
\qquad\Longleftrightarrow\qquad
\operatorname{row}(J_F)\subseteq\operatorname{row}(J_C).
$$

*Proof.* "No dangerous $v$" means $v\in\ker(J_C)\Rightarrow v\in\ker(J_F)$, i.e. $\ker(J_C)\subseteq\ker(J_F)$. In finite dimension with the standard inner product $\ker(M)=\operatorname{row}(M)^\perp$, so taking orthogonal complements reverses the inclusion: $\ker(J_C)\subseteq\ker(J_F)\Leftrightarrow\operatorname{row}(J_F)\subseteq\operatorname{row}(J_C)$. $\blacksquare$

**Counterexample to the intersection condition.** Take $d_\Delta=2$, $J_C=\begin{pmatrix}0&1\end{pmatrix}$, $J_F=\begin{pmatrix}1&1\end{pmatrix}$. Then $\ker(J_C)=\operatorname{span}\{(1,0)\}$, $\operatorname{row}(J_F)=\operatorname{span}\{(1,1)\}$, and

$$
\ker(J_C)\cap\operatorname{row}(J_F)=\{0\},
$$

so the intersection condition is satisfied. Yet $(1,0)\in\ker(J_C)$ and $J_F(1,0)^\top=1\neq0$, so $(1,0)$ is dangerous. Hence $\ker(J_C)\cap\operatorname{row}(J_F)=\{0\}$ is necessary but not sufficient; the correct requirement is the containment of Proposition A.1.

### A.2 What "no contraction" means (precision vs. marginal variance)

With linear-Gaussian posterior precision $\Sigma_{\Delta\mid C}^{-1}=\Sigma_\Delta^{-1}+M$, $M=J_C^\top\Sigma_{\mathrm{obs}}^{-1}J_C\succeq0$, a direction $v\in\ker(J_C)$ satisfies $Mv=0$, hence

$$
\Sigma_{\Delta\mid C}^{-1}v=\Sigma_\Delta^{-1}v,
$$

so the likelihood adds no information along $v$ and the *conditional* variance of $\langle v,\Delta\rangle$ given the other coordinates is unchanged. The *marginal* variance $v^\top\Sigma_{\Delta\mid C}v$ can still be strictly smaller than $v^\top\Sigma_\Delta v$ when the prior is correlated.

**Counterexample.** Let $\Sigma_\Delta=\begin{pmatrix}1&\rho\\\rho&1\end{pmatrix}$ and $M=\operatorname{diag}(0,m)$ with $m>0$ (the data inform only $e_2$; $v=e_1\in\ker(J_C)$). A direct computation gives

$$
[\Sigma_{\Delta\mid C}]_{11}=\frac{1+m(1-\rho^2)}{1+m},
$$

which is $<1=[\Sigma_\Delta]_{11}$ whenever $\rho\neq0$, and equals $1$ only when $\rho=0$. Thus the marginal posterior variance along the unobserved direction contracts under a correlated prior. The invariant statement is therefore about the precision / conditional variance, not about marginal contraction.

### A.3 Diagnostic

Under the fitted model, report the principal angles between $\operatorname{row}(J_F)$ and $\operatorname{row}(J_C)$, or the normalized residual

$$
\rho_{\mathrm{miss}}
=
\frac{\bigl\|J_F\,(I-P_{\operatorname{row}(J_C)})\bigr\|}{\|J_F\|},
$$

where $P_{\operatorname{row}(J_C)}$ projects onto the early-observable subspace. $\rho_{\mathrm{miss}}=0$ certifies that all future-relevant directions are observed; $\rho_{\mathrm{miss}}>0$ quantifies the forecast-relevant information the early protocol misses.
