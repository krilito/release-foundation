# Script Route Decision Map, 2026-06-14

This file is a decision map for the numbered scripts. It does not replace
`project_archaeology_inventory_2026-06-12.md`; it compresses that archaeology
into a practical answer to one question:

```text
which parts of scripts 0-123 still carry the project forward,
which parts are only supporting material,
and which parts should stop receiving new effort?
```

## Short Answer

The project is not "all wrong." The real problem is that many scripts explored
different scientific questions before one paper route was locked.

The current live route is:

```text
static descriptors under-identify release;
measured early observations expose missing release state;
future-release design is an observation-budget problem.
```

Everything below is classified against that route.

These areas generated useful negative evidence, but they should not be treated
as the next natural step.

|---|---|
| generic RSSM / world-model line (`71_*`) | current data do not support it as a stable scientific claim |
| release-transfer / LNN fantasy (`78-90` and archived transfer lines) | cross-system transfer is not solved and strong baselines already exposed the weakness |
| symbolic or SRDS-like cascades | pseudo-label identifiability and fragile semantics |
| "active observer is the best predictor" story | bug-fixed audits demoted it to scheduling/UQ support |
| static-only exact curve prediction as the final answer | under strict splits it behaves like a source-local prior, not a sufficient solution |

Interpretation:

- These are not shameful failures.
- They are closed doors.
- Reopening them without a new preregistered gap statement is scope creep.

## What The User Already Did Right

Yes, the project was already classified before this file existed.

The earlier classification lives in:

- `project_archaeology_inventory_2026-06-12.md`
- `README.md`
- `docs/INDEX.md`

What was still missing was a sharper split between:

1. scripts that support the main claim now,
2. scripts that belong only in supplement or discussion,
3. scripts that should no longer attract new optimization effort.

This file exists to make that split explicit.

## Current Project Verdict

The project should not be judged as a failed search for one better model.

It should be judged as:

```text
a wide exploration that eventually isolated one durable claim
and many necessary negative boundaries.
```

That means:

- the strongest scientific asset is not a model family;
- it is the information-budget result plus its legal task definition;
- the main danger now is not "no hope";
- the main danger is drifting back into retired model invention.

## Current Allowed Next Work

If new work starts now, it should come from one of these three bins only:

1. tighten the main evidence table and manuscript around `91-107`;
2. use `118-123` to formalize legal measurement, route, and screening objects;
3. add data only when it improves observability rather than merely increasing
   row count.

The next work should not be:

- a new neural architecture sprint,
- a new cross-system predictor claim,
- a route-model claim before cross-source route facts exist,
- or a screening-platform headline beyond within-system PLGA classical entry.
