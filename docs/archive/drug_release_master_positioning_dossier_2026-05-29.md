## 1. One-page verdict

### What the field is doing now

The external field is still dominated by:

1. `descriptor-only supervised release prediction`
2. `descriptor + sparse early-point forecasting`
3. `mechanism-local kinetic / assay workflows`
4. `platform / optimization / formulation-AI systems`
5. `data / schema / benchmark infrastructure`

The field is **not** yet organized around a shared partially observed
release-intelligence interface.

### Where we sit now

The current project is no longer just a PLGA regressor. It already has:

- an audited PLGA forecasting core
- a shared benchmark contract
- a first non-PLGA bridge through liposome
- a shared posterior-family object
- a calibrated-family panel across `PLGA + liposome`
- a locked preregistered chitosan prospective stress test

### How bold we can be

Safe boldness now:

> unified drug-release intelligence

Unsafe boldness now:

> universal solved drug-release model

### Biggest remaining gap

The biggest systems gap is no longer curve-space benchmarking. It is:

> route-consistent uncertainty-aware duration / shape reporting
